10. FILTER SEMANTICS
============================================================

Filters must combine logically.

Use:

AND between filter dimensions.

Example:

keyword = software
location = Montreal
category = Software Engineering

means:

jobs matching the software query
AND Montreal
AND Software Engineering.

Within a multi-select dimension, if the existing UX supports multi-select, use sensible OR semantics.

Do not create confusing filter behavior.

Blank/unset filters must not restrict results.
